# 🏝️ Fugo: Archipelago

> *By day, you build an empire. By night, you defend it from what the archipelago becomes.*

A procedural island strategy game with day/night survival, built with React + TypeScript + Canvas 2D.

**[🎮 Play Now](https://cyhtm.github.io/fugo/)**

## 🎮 Gameplay

### ☀️ Day Phase (60s)
- Explore procedurally-generated islands
- Build farms, lumber mills, quarries for resources
- Construct walls, towers, and lighthouses for defense

### 🌅 Sunset (8s)
- The sky turns orange, darkness approaches
- Final seconds to prepare your defenses

### 🌑 Night Phase (40s+)
- Islands mutate, creatures emerge from the deep
- Waves of enemies attack your settlements
- Towers and lighthouses auto-attack

### 🌅 Dawn
- Assess the damage
- Collect Night Essence from fallen creatures
- Rebuild and prepare for the next night

## 🕹️ Controls

| Input | Action |
|-------|--------|
| WASD / Arrows | Pan camera |
| Scroll Wheel | Zoom in/out |
| Right-drag | Pan camera |
| Left-click | Select island / Place building |
| 1-6 | Quick-select building |
| Right-click | Cancel placement |
| H | Toggle help |
| R | Restart (game over) |

## 🛠️ Development

```bash
# Install
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🏗️ Tech Stack

- **React 19** + **TypeScript**
- **Vite** for builds
- **Canvas 2D API** for rendering
- **GitHub Pages** for hosting
- **GitHub Actions** for CI/CD
